# Gathered PWA v1

This is the first working Gathered prototype.

Included:
- Today screen
- Bottom navigation
- Quick Add / Inbox capture
- Simplify Today modes
- Editable Today's Anchor
- Household preview
- Commonplace + Seasonal placeholders
- PWA manifest + service worker for installability/offline shell

Important:
A PWA must be served over HTTPS (or localhost) for install/offline features to work correctly.
You can preview the files locally in a browser, but Android installation requires hosting.
